Scripts de las vistas y archivos de insercion de datos (Generados por ChatGPT)

Vistas:

VistaPorcentajeEleccion: Muesta la informacion sobre la eleccion, el candidato, partido, cargo y porcentaje de votos con el uso de las columnas eleccionID, eleccionNombre, Candidato, nombrePartido, nombreCargo, porcentaje.

VistaPostulantesPorPartido: Muestra la lista de los candidatos, por cada partido, que participan de la eleccion. Incluye las columnas nombrePartido, candidato, eleccionNombre, nombreCargo, porcentaje, posicion.

VistaHistorialVotos: Muestra el historial de voros de los votantes, indicando a quien le corresponde cada voto, el partido del candidato y la fecha del voto.
